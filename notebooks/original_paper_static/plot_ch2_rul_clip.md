## 图2-5: RUL 标签截断前后对比图 (3台发动机)

> **建议插入位置**: §2.2.2 "RUL 标签定义"，公式(2-5) `$R_{max}=125$` 之后

**说明文段**: 图2-5 展示了 FD001 训练集中三台不同寿命发动机的 RUL 标签在截断前后的对比。灰色虚线表示原始线性递减标签 $RUL = T - t$，红色实线表示经过分段线性处理后的截断标签 $\widetilde{RUL} = \min(T - t, 125)$。蓝色虚线标注了截断阈值 $R_{max}=125$，灰色半透明区域表示被截断的寿命早期段。

从图中可观察到：
1. **长寿命发动机截断效果显著**: Engine #2 总寿命 287 cycles，前 162 个 cycle (占寿命 56.4%) 的原始 RUL 从 286 降至 0 被统一截断为 125，避免了早期健康阶段大范围标签波动对模型的干扰。
2. **中等寿命发动机部分截断**: Engine #1 总寿命 192 cycles，前 67 个 cycle 被截断，交拐点位于 Cycle=67, RUL=125 处。
3. **短寿命发动机几乎无截断**: Engine #91 总寿命 135 cycles，仅前 10 个 cycle 被截断，说明其大部分运行周期已处于明显退化阶段。
4. **统一退化预警区间**: 三台发动机在截断后的退化阶段 (RUL∈[0,125]) 标签完全一致，使模型能够专注于学习临近失效前的关键退化模式。

## 图2-6: RUL 标签截断机制详解 (Engine #2 大图)

> **建议插入位置**: §2.2.2，作为对图2-5的补充详细说明

**说明文段**: 图2-6 以 Engine #2（总寿命 287 cycles）为例，详细展示了 RUL 标签截断机制。图中标注了两个阶段：

- **健康/早期退化阶段** (Cycle 1~162, 黄色底标注): 原始 RUL > 125，传感器变化不显著。此阶段标签统一截断为 125，使模型避免在缺乏明显退化信号的区间学习大范围 RUL 回归。
- **明显退化阶段** (Cycle 163~287, 红色底标注): 原始 RUL ≤ 125，标签随运行周期线性递减。此阶段传感器已呈现可观测的退化趋势，是模型学习的重点区间。

截断点位于 Cycle=162, RUL=125 处（红色圆点标注），此后的标签从 125 开始线性递减至 0。这种分段处理方式使模型能够将注意力集中在对维修决策更具实际意义的退化预警区间。
