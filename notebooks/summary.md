# 📝 动态图 STGNN 实验总结与论文写作要点

> 本文档梳理三次递进实验的数据、对应论文段落，并说明动态图的特点、优势、工程价值与最终选型。
> 数据来源：`logs/dynatopo/eval_full_FD001.json`、`experiments/logs/summary.json`、`logs/dynatopo/eval_cross_condition.json`。

---

## 0. 问题背景：为什么引入动态图

静态图 STGNN（MSTCN + GAT，Spearman 固定拓扑）在**跨工况**场景下暴露明显短板：

| 迁移设置 | static 跨工况表现（FD002/FD003/FD004） | 结论 |
|---|---|---|
| 无迁移 | 77.51 / 72.60 / 80.41 | 直接跨域失效 |
| 无监督 UDA | 77.58 / 53.52 / 58.87 | LMMD 对齐失效，几乎无改善 |
| 监督式迁移 | 25.65 / 14.59 / 34.37 | 有目标域标签才恢复正常 |

> **核心问题**：固定 Spearman 图是在 FD001 单工况上一次性算好的，无法反映 FD002~FD004 多工况下传感器相关结构的变化。当目标域没有标签（无迁移、UDA）时，静态图缺少适应目标域工况的通道，性能崩溃。

为此引入**工况驱动的动态拓扑图**：在静态图之外，新增一条"根据工况参数（op1~op3）动态生成传感器图"的分支，形成 2×2 策略矩阵：

| | B1 特征层融合（各自 GAT） | B2 拓扑层融合（合并边） |
|---|---|---|
| **A1 余弦相似度生成** | A1B1 | A1B2 |
| **A2 多头注意力生成** | A2B1 | A2B2 |

**初始优选标准**：`val RMSE` 定排名，`val NASA Score` 做否决（NASA 过高即使 RMSE 最低也需警惕）。

---

## 指标使用规范：val 与 test 的分工

**核心铁律：验证集做决定，测试集只做报告。**

| 场景 | 用哪个指标 | 为什么 |
|---|---|---|
| 模型选择（四种动态图谁更好） | **val** RMSE + val NASA | 验证集是训练过程中的"选择工具" |
| 早停（early stopping） | **val** loss | 监控验证损失，避免过拟合 |
| 多 seed 排名 | **val** RMSE | 铁律：不从多个 seed 里挑 test 最好的 |
| 论文最终报告的性能数字 | **test** RMSE + test NASA | 测试集只碰一次，是无偏的最终裁判 |

**为什么不能反过来？**

- 若用 **test** 去选模型：test 会被反复"看"，信息间接泄漏进选择过程，它就不再是"完全没见过的数据"的无偏估计，报告的分数会虚高。
- 若用 **val** 去做最终报告：验证集被训练过程反复使用过（早停、选 seed），其分数同样偏高、不可信。

所以二者角色不可互换：**val 用于"做决定"，test 用于"做证明"**。

**为什么 val NASA 与 test NASA 量级差这么多？**

- `val NASA` 在**截断标签**（RUL 截断到 ≤125）上计算 → 量级约 1.1万~1.4万。
- `test NASA` 在**真实 RUL** 上按 C-MAPSS 官方非对称评分计算 → 量级约 350~620。
- 两者是不同标签空间下的评分，**绝对数值不可比**，只能各自在其集合内做排序/否决。

> **论文段落（第一次实验）**：在 FD001 单工况数据集上，对静态基线及四种动态拓扑组合进行训练与验证。结果表明，各模型验证集 RMSE 均集中于 13.0~13.6 区间，未呈现稳定可分性。考虑到单工况下操作条件（op1~op3）方差接近零，"工况感知"失去可区分的输入变化，动态拓扑难以发挥其设计优势；且单次实验的验证集仅含 20 台发动机，指标噪声较大。为此进一步采用多种子重复实验以稳定排名。

| A2B2 | 15.18 ± 0.56 | 454.1 ± 87.9 | **13.24 ± 0.25** | 11088.6 ± 1403.1 |

### 结论与论文段落

各模型指标均值区间大量重叠，**无统计显著差异**；但 **A1B2 在 test RMSE、test NASA、val RMSE、val NASA 四项指标上的方差均最高**（有 seed 的 test RMSE 高达 18.04、val NASA 标准差达 3178.1），且 **val NASA 均值也最高（12294.9）**，按"val NASA 做否决"的标准触发否决，稳定性最差，**先行排除 A1B2**。其余四模型 val NASA 均值接近（11088~11306），无否决风险。

> **论文段落（第二次实验）**：为进一步消除单次训练的随机性，对五种模型各进行 5 个随机种子的重复训练。结果表明各模型指标均值仍无显著差异（均值±标准差区间相互重叠），说明在单工况 FD001 下动态拓扑相对静态基线不构成统计显著优势。值得注意的是，A1B2（相似度生成×拓扑层融合）在 test RMSE、NASA Score、val RMSE 与 val NASA Score 上均表现出最高离散度（如 test RMSE 标准差达 1.11、val NASA 标准差达 3178.1），且 val NASA 均值亦最高，说明该组合在单工况下的训练稳定性不足且存在过晚预测倾向，故后续实验排除 A1B2。考虑到动态拓扑的设计动机在于工况感知，单工况难以体现其价值，后续转入多工况迁移学习实验。

## 4. 动态图的特点、优势与机制解释

### 4.1 两类生成器的本质差异（决定实验结果的关键）

| 生成器 | 拓扑计算核心 | 可训练部分 | 跨域行为 |
|---|---|---|---|
| **A1 相似度** | 余弦相似度（无参几何规则） | 仅特征投影 + 工况缩放 | 输入自适应，天然跨域鲁棒 |
| **A2 注意力** | 多头注意力 Q·Kᵀ | Q/K 投影 + 196 维工况偏置 | 源域特化，需迁移重校准 |

### 4.2 为什么呈现"无迁移 A1 强、UDA 后 A2 反超"的现象

- **无迁移**：A1 的相似度规则"输入变、图就跟着变"，不依赖源域特化的映射，跨域即稳定；A2 的注意力映射在 FD001 上过拟合，无迁移时在 FD002~FD004 生成错误拓扑，反而劣于静态图。
- **UDA**：A2 的可训练参数可通过 LMMD 梯度在目标域工况下重新校准，一旦校准成功，其更灵活的拓扑表达能力带来更大收益；而 A1 因无参规则缺少可被对齐"调优"的自由度，UDA 增益有限（在三种动态图中 UDA 表现相对最弱）。

> **机制解释段落（可写入论文）**：动态拓扑在无监督迁移中的增益源于其"输入自适应"特性——无论是否经过迁移训练，拓扑均随目标域输入（尤其工况参数）实时重算，从而在拓扑层面缓解了源域与目标域之间传感器条件依赖结构的偏移。固定 Spearman 图则完全冻结于源域，无法反映目标域工况下的结构变化，导致 LMMD 特征对齐失效。进一步地，相似度生成器（A1）以无参几何规则为核心，天然跨域稳定；注意力生成器（A2）则具备更强的表达灵活性，在无标签场景下经 LMMD 梯度重新校准后可获得更大收益。

### 4.3 动态图的三点优势

1. **拓扑随工况自适应**：图不再固定，而是每个样本、每个工况实时生成。
2. **无需目标域标签即可生效**：动态图利用的是工况参数（op1~op3，属输入特征而非标签），在 UDA 下依然可用。
3. **直接解决"拓扑层分布偏移"**：跨工况变化的不只是特征分布，更是传感器间的依赖结构，动态图从拓扑源头适应。

### 4.4 工程价值

航空发动机 RUL 标签依赖昂贵的 run-to-failure 试验，新机型/新工况下"运行数据充足、失效标签稀缺"。UDA 使模型仅凭目标域无标签运行数据即可完成跨工况迁移，是将 RUL 预测推向真实 PHM 工程的关键；而动态拓扑进一步解决了固定图在域偏移下对齐失效的问题，使无标签迁移真正可用。

## 5. 最终选型讨论

### 5.1 两种候选的客观画像

| 维度 | A1B1 | A2B2 |
|---|---|---|
| 无迁移跨域 | ✅ 显著最优（44.6~49.0） | ❌ 最差（83~86） |
| UDA 无标签迁移 | 一般（51.6/43.3/50.2，三动态图中偏弱） | ✅ 最优且最稳（46.9/45.1/45.3） |
| 监督式迁移 FD004 | ❌ 异常（43.21） | ✅ 正常（34.62） |
| 多 seed 单工况 val | 13.60 ± 0.15 | ✅ 13.24 ± 0.25（最优） |
| 方法学契合度 | 相似度可解释 | ✅ 注意力×拓扑融合，最契合"工况驱动" |

### 5.2 选型结论（推荐）

**推荐以 A2B2（多头注意力 × 拓扑层融合）为最终方案**，理由：

1. **论文主线是 UDA 无标签迁移**（这是工程价值所在），而 A2B2 在 UDA 主场 3 个目标域中 2 个最优、1 个次优，且 RMSE 稳定在 45~47，鲁棒性最好；
2. 多 seed 单工况验证集上 A2B2 亦为最优且标准差最小（13.24 ± 0.25）；
3. A2B2 的"注意力生成 + 拓扑层融合"最能代表"工况驱动拓扑"的方法学创新。

**同时保留 A1B1 作为独立亮点**：其无迁移即达 44~49 RMSE（远优于静态基线 72~80）的现象，可作为"相似度拓扑天然跨域鲁棒"的补充证据，说明即使不迁移，相似度动态图也具备显著的跨工况泛化能力。

### 5.3 决策框架（供最终定稿参考）

| 论文主线 | 推荐选型 |
|---|---|
| 主打"无标签 UDA 迁移"（工程价值最大） | **A2B2**（UDA 最优且最稳） |
| 主打"零成本跨域泛化"（不迁移即鲁棒） | A1B1（无迁移显著优势） |

> 若两线并重：正文主推 A2B2（UDA 主场），另设小节讨论 A1B1 的无迁移泛化优势，二者共同支撑"工况驱动动态拓扑提升跨工况 RUL 预测性能"的总论点。

## 6. 一句话总结全文论证链

> 静态图在跨工况无标签场景下因拓扑冻结而失效 → 引入工况驱动动态拓扑 → 单工况下无显著差异（符合设计预期）→ 多工况监督式迁移下被标签信号掩盖 → **多工况无监督 UDA 下动态图显著优于静态基线** → 选 A2B2（UDA 最优且最稳），并以 A1B1 的无迁移泛化作为补充亮点 → 验证动态图的工程价值：**跨型号/工况下的高 RUL 预测性能，尤其在无标签约束下依然有效**。
